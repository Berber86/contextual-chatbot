# `legacy/` — мёртвый код

**Этот каталог не участвует в работе приложения.** Ни один файл отсюда не
подключается в `index.html`, не импортируется и не вызывается. Здесь лежат
снимки прежних архитектур — чтобы было с чем сравнивать текущую версию.

| правило | как есть |
|---|---|
| сборка и деплой | `legacy/` исключён в `.vercelignore` |
| тесты | тестовые файлы внутри переименованы в `*.legacy-tests.cjs`, поэтому обычный `node --test` их не находит и не запускает |
| язык репозитория | помечены как vendored в `.gitattributes`, GitHub не считает их в статистике |
| правки | не вносить: это музейный экспонат, а не код |
