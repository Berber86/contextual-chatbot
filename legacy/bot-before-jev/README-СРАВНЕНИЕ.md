## Как воспроизвести и что здесь изменено

```bash
git archive aee911f | tar -x -C legacy/bot-before-jev
```

Отличия от чистого архива — два, оба чтобы слепок не мешал живой работе:

1. **`assets/emoji/` не вложен** (1,2 МБ картинок). К архитектуре отношения не
   имеет; из-за него `index.html` из этого каталога покажет битые эмодзи.
2. **Тесты переименованы** из `*.test.cjs` в `*.legacy-tests.cjs`: иначе
   обычный `node --test` из корня репозитория подхватил бы их и они читали бы
   файлы текущей версии.

Запуск слепка:

```bash
cd legacy/bot-before-jev
node dev-server.mjs                          # демо-сервер на :3000, без ключей
node --test tests/*.legacy-tests.cjs         # 134 проверки, 0 падений
```

1. `council.js` — реестр линз: `route` (4 вопроса), `safety` (2), `greeting` (1),

   слияние, переименование; защита от вымысла рядом.
4. `MODEL_ROUTING.md` — вся логика решений текстом: пороги, стоимость, отказы.

## Чего в слепке нет

Ни `jev.js`, ни `council.js`, ни `api/systemone.js`, ни облаков памяти: в этом
снимке `grep -c CLOUD_CONFIG app.js` даёт 0, в текущей версии — 18. Облака
появились уже после jev, поэтому «до и после» именно по ним этот снимок
показывает корректно: до — их нет вовсе.
